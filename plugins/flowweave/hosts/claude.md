# FlowWeave for Claude

Use the FlowWeave Agent Inbox v2 instructions when working in Claude Desktop, Claude Code, or Claude Code CLI.

Read the exact run-specific `.flowweave/runs/<run-id>/agent-request.json` path provided by FlowWeave and write exactly one Agent Inbox v2 `agent-response.json` to the exact `responsePath` in that request. Do not return the final artifact only in chat or stdout.
